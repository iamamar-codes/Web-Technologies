Paired Tags

Tags that include Opening and closing Angular brackets.

1. Paragraph Tag: Use to Wright Paragraph in web page.

2. Underline Tag: This tag is used to underline any word or line.

3. Heading Tags: Heading Tag includes 6 tags from h1 to h6, h1 is biggest font size and h6 is smallist font size. Used to write heading, subheading and other information.

4. Bold Tag: Used to emphices the perticular word or a line.

5. Mark Tag: This tag is used to Highlight something.


Unpaired Tags

Tag that includes only self closing Angular brackets.

1. Break Tag: Using this tag cursor will shift to the next line.

2. Horizontal Tag: It create a Horizontal line on the page.

3. Image Tag: This tag is used to add image on a web page.
